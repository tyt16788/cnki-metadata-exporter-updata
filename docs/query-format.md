# 检索配置格式

推荐使用 JSON 数组，每个对象代表一个独立检索集合：

```json
{
  "id": "Q1",
  "name": "集合名称",
  "field": "SU",
  "query": "SU=('关键词一'+'关键词二')",
  "purpose": "可选用途说明",
  "tier": "可选数据层级"
}
```

必填字段为 `id`、`name` 和 `query`。集合编号只使用字母、数字、点、下划线和连字符。

可选字段 `publication_time` 用于填写发表时间起止日期，格式如下：

```json
"publication_time": {
  "start": "2010-01-01",
  "end": "2018-12-31"
}
```

`start` 和 `end` 必须同时提供，且使用包含边界的 `YYYY-MM-DD` 日期。原生导出命令对未配置时间范围的集合默认使用上一个完整自然月；已有范围优先使用配置值。传入 `--all-time` 可关闭该默认时间限制。

原生导出默认将单个发表时间范围限制在 6000 条以内；超出时按日期二分并递归检索，直到每个时间片可稳定分页。可通过 `--max-results-per-slice` 调整上限。若单日结果仍超过上限，程序会报错，需要缩小检索式或调整上限。

也可以从结构化 DOCX 中提取。默认从以“四 CNKI”开头的标题读取，遇到以“五 Web of Science”开头的标题停止；每个集合采用“编号 + 空格 + 名称”“检索式：字段=表达式”“用途：说明”的段落格式。标题可通过命令行参数修改。

,

 {

  "id": "Q2",

  "name": "材料与磨损交叉集",

  "field": "TKA",

  "query": "TKA=('耐磨钢'+'耐磨合金钢') * ('磨损'+'摩擦磨损'+'耐磨性能')",

  "purpose": "演示题名、关键词和摘要联合检索",

  "tier": "性能研究"

 }
